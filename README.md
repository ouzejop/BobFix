# BobFix

**Proven fixes, not guesses.**

BobFix turns debugging into an evidence-driven investigation inside IBM Bob IDE:
bug report → parallel investigation (frontend / backend / data subagents) → evidence →
hypotheses → root cause → fix → tests → **verified fix**.

Built for the IBM Bob 2.0 Hackathon (lablab.ai, September 2026).
